# dev-down

Site e downloads do **MRRDEV-Download**, gerenciador de downloads para Windows.

- Site: https://dev-down.marreira.dev
- Downloads: [releases](https://github.com/marreiradigital/dev-down/releases/latest)

Aqui ficam apenas o site e os arquivos prontos (instalador e extensão). O código-fonte é privado.

| Arquivo | Para que serve |
|---|---|
| `index.html` | A página de download |
| `latest.json` | Manifesto que o programa consulta para saber se há versão nova (assinado) |
| `extensao.json` | Versão da extensão, consultada por ela mesma para avisar o usuário |
